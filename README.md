## 如何下载代码
1. 点击仓库右上角的 `Code` → `Download ZIP`，直接下载全部代码；
2. 也可以单独点击某个代码文件，右上角 `Raw` → 右键“另存为”保存单个文件。

## 运行说明
- Python 代码：安装Python后，终端执行 `python 文件名.py`；
- C++ 代码：用VS/Dev-C++编译运行，或终端 `g++ 文件名.cpp -o 程序名 && ./程序名`；
- Java 代码：安装JDK后，终端执行 `javac 文件名.java && java 类名`。
